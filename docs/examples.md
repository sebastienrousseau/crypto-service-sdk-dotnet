# Examples

Each example in
[`examples/`](https://github.com/sebastienrousseau/crypto-service-sdk-dotnet/tree/main/examples)
is a console project that checks its own result and exits non-zero on
a wrong one. CI runs every one against crypto-server
(`scripts/run-examples.sh`); run them from the repository root with
`CRYPTO_SERVICE_URL` and `CRYPTO_SERVICE_API_KEY` set.

| Example | Shows |
| :--- | :--- |
| `Hash` | `HashAsync` with SHA-256 and BLAKE3, checked against the FIPS 180-2 vector |
| `AeadRoundTrip` | `EncryptAsync` and `DecryptAsync`, and a secretbox bound to AAD |
| `SignVerify` | A server-held Ed25519 key: generate, sign by keyId, verify, delete |
| `MlKem` | ML-KEM-768: encapsulate to the public key, decapsulate by keyId |
| `ErrorHandling` | A validation problem with its fields, a 404, a 401 and a transport error |
| `Concurrent` | Twelve calls in flight on one client, with retries and a deadline |

```sh
dotnet run --project examples/SignVerify
```

Keys in the examples are synthetic constants or generated by the server
for the run, and every server-held key they create is deleted.
